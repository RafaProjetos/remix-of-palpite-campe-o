The login screen (`src/routes/entrar.tsx`) will be modified to:
- Add a toggle button (eye icon) to show/hide the password.
- Add a "Forgot Password" link that triggers Supabase's password reset email flow.
- A new route or dialog will be used to handle the email input for password recovery.
